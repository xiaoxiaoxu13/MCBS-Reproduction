# MCBS：基于改进冲突搜索的多无人机时空协同路径规划

本项目实现了 **MCBS（Modified Conflict-Based Search）** 算法，用于解决多无人机（UAV）的**时空协同路径规划**问题。在经典 CBS 算法的基础上，MCBS 同时处理**空间冲突**与**时间冲突**，使多架无人机能够在满足运动学约束的前提下安全、协同地到达各自目标。

## 项目背景

多无人机路径规划中，除避免碰撞（空间协同）外，还需考虑**到达时间的一致性**（时间协同）。例如在编队、同步打击或协同侦察任务中，各无人机需在允许的时间差范围内（`T_TAR`）到达目标点。

经典 CBS 算法仅解决空间冲突，无法保证时间协同。本项目提出的 **MCBS** 在 CBS 框架中引入：

- **时间冲突检测**：当任一无人机路径长度与最长路径之差超过 `T_TAR` 时触发
- **时间冲突消解策略**：
  - **目标点等待（goal-waiting）**：在终点原地等待一步，O(1) 分支代价
  - **末段约束绕行**：约束路径末段少量中间点，迫使低层 A* 自然延长路径（上限 3 个分支）
- **带惩罚项的代价函数**：`cost = base + ωₛ·nₛ + ωₜ·Δt`，引导搜索优先消除冲突

## 算法原理

### 整体架构：双层搜索

```
┌─────────────────────────────────────────────────┐
│  高层（MCBS）：约束树 CT 搜索                     │
│  - 检测冲突 → 分支约束 → 重规划 → 选最优          │
└────────────────────┬────────────────────────────┘
                     │ 调用低层规划器
┌────────────────────▼────────────────────────────┐
│  低层（Sparse A*）：单机路径规划                  │
│  - Dubins 运动模型 + 时空约束 + 目标引导动作      │
└─────────────────────────────────────────────────┘
```

### 冲突类型与处理

| 冲突类型 | 定义 | 消解方式 |
|---------|------|---------|
| **顶点冲突 (Vertex)** | 两机同一时刻距离 < `D_SAFE` | 对两机分别添加点约束，各分支重规划 |
| **边冲突 (Edge)** | 两机在相邻时刻位置互换（对穿） | 对两机分别添加连续两点约束 |
| **时间冲突 (Time)** | 路径长度差 > `T_TAR` | goal-waiting + 末段约束绕行 |

### 代价函数

```
cost = Σ path_length + ωₛ · (空间冲突数) + ωₜ · Σ(最长路径 - 各机路径)
```

- `ωₛ`（`OMEGA_S`）：空间冲突惩罚权重
- `ωₜ`（`OMEGA_T`）：时间不协同惩罚权重

### 运动学约束（Dubins 模型）

低层 A* 生成符合无人机运动学的路径：

- **步长**（`STEP_SIZE`）：每步移动距离
- **最小转弯半径**（`R_MIN`）：限制最大偏航角
- **最大爬升角**（`THETA_MAX`）：限制高度变化率
- 每步扩展 5 种转向 × 3 种高度变化 = 15 个候选动作，外加 1 个目标引导动作

## 快速开始

### 1. 交互式可视化（默认场景）

```bash
python visualize.py
```

运行后将在 `crossing_3` 场景下执行 MCBS、Sparse A* Only、CBS 三种算法，并弹出路径可视化图。

### 2. 运行预设场景

```bash
python visualize.py --presets
```

包含 5 个预设场景：`crossing_2`、`crossing_3`、`parallel_2`、`parallel_3`、`random_2_seed0`。

### 3. 随机场景实验

```bash
python visualize.py --random --n=10 --agents=2
```

- `--n`：场景数量
- `--agents`：每场景无人机数量

### 4. 批量实验（预设 + 随机）

```bash
python visualize.py --batch
```

运行所有预设场景及随机生成的 2 机/3 机场景，结果追加写入 `results.csv`。

### 5. 在代码中调用

```python
from mcbs import mcbs

starts = [(20, 20, 0), (80, 80, 0)]
goals  = [(80, 80, 0), (20, 20, 0)]

solution, stats = mcbs(starts, goals)

if stats['success']:
    print(f"总路径长度: {stats['total_path_length']:.2f}")
    print(f"到达时间标准差: {stats['arrival_time_std']:.3f}")
    print(f"最小两两距离: {stats['min_pairwise_dist']:.3f}")
```

## 配置参数

所有参数集中在 [config.py](file:///d:/00projects/MCBS/config.py)：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `MAP_SIZE` | (100, 100, 50) | 三维地图大小 (X, Y, Z) |
| `STEP_SIZE` | 2 | 每步移动距离 |
| `R_MIN` | 1.5 | 最小转弯半径 |
| `THETA_MAX` | 30 | 最大爬升角（度） |
| `D_SAFE` | 3 | 安全距离（两机最小间距） |
| `V` | 1 | 无人机速度（时间 = 路径点索引） |
| `T_TAR` | 1 | 允许的最大到达时间差（步数），定义于 `conflict.py` |
| `TIMEOUT` | 60 | 高层搜索超时（秒） |
| `MAX_CT_NODES` | 10000 | 约束树最大展开节点数 |
| `LOW_LEVEL_MAX_STEPS` | 50000 | 低层 A* 最大搜索步数 |
| `GOAL_THRESHOLD` | 3.0 | 终点判定阈值（1.5 × STEP_SIZE） |
| `OMEGA_S` | 10 | 空间冲突惩罚权重 |
| `OMEGA_T` | 5 | 时间冲突惩罚权重 |

## 实验结果

`results.csv` 记录了三种算法在多场景下的对比实验，关键结论：

### 算法对比

| 算法 | 空间冲突处理 | 时间冲突处理 | 代价函数 |
|------|:----------:|:----------:|---------|
| **MCBS** | 是 | 是 | 含 ωₛ、ωₜ 惩罚项 |
| **CBS** | 是 | 否 | 仅路径长度和 |
| **Sparse A* Only** | 否 | 否 | 无协同（基线） |

### 典型结果示例

以 `crossing_3` 场景（3 机交叉飞行）为例：

- **MCBS**：成功，到达时间标准差 ≈ 0.47（时间协同），最小间距 > D_SAFE（无碰撞）
- **CBS**：成功解决空间冲突，但到达时间标准差 ≈ 5.9（时间不协同）
- **Sparse A* Only**：产生 5 个冲突（2 顶点 + 2 边 + 1 时间）

### 关键观察

1. **MCBS vs CBS**：两者均能消除空间冲突，但 MCBS 通过时间惩罚项显著降低了到达时间标准差，实现时间协同
2. **MCBS vs Sparse A* Only**：基线方法虽速度快但存在大量冲突，MCBS 以可接受的额外计算开销换取无冲突解
3. **时间协同效果**：MCBS 在 `arrival_time_std` 指标上明显优于 CBS，验证了时间冲突处理机制的有效性
